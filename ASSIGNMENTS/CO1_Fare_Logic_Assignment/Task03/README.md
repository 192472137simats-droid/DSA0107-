## Description
Evaluates primitive system types using `sizeof` and `<climits>`.
Proves that floating-point representations introduce accumulating precision drift over many transactions, justifying `long long` integer paise for monetary storage.

## Compilation and Execution

g++ -std=c++17 -Wall -Wextra -o DataTypesAudit.exe DataTypesAudit.cpp
./DataTypesAudit.exe
