## Description
Resolves compiler ambiguities in function overloading when default arguments are combined.
Demonstrates overload resolution across primitive types (`int` grams, `double` kg) and user-defined `Parcel` structures.

## Compilation and Execution

g++ -std=c++17 -Wall -Wextra -o CourierCalculator.exe CourierCalculator.cpp
./CourierCalculator.exe
